# Retired hero film

`hero.mp4` and `hero-poster.jpg` were the original hero: a generated 5-second
clip of five women pointing at one another's cheeks.

Replaced 2026-09-01 after feedback that it read as AI. It did, for five
reasons, and only two were about render quality: the gesture was invented,
the backdrop was a seamless cream infinity with no room, generative motion
warped hands and hair, the casting was uniform, and it said nothing only
BeFound could say.

It also argued against the page beneath it. `/skin-read/` promises "Real skin.
Real barrier movement. No filters, no perfect lighting."

Replaced by `hero-dome.jpg` — the studio's own imaging dome, a real
photograph outpainted to 16:9.

To revert: copy both files back to the parent folder and restore the `<video>`
element in the hero. `git log -- hero.mp4` will find the markup as it was.
